# v12 Natural Card Patch

This patch improves the generated social player card by keeping the original Yuvaan footballer hair, ears, body pose, and stadium background while pasting a smaller selfie face into the face area.

It also applies a selected-country uniform tint to the jersey area using canvas blending instead of placing a separate jersey box on top.

This is still a lightweight browser-based canvas renderer. It does not perform AI face swapping. For truly natural identity-preserving face replacement, you would need a backend image generation or face-swap service.
