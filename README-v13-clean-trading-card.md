# v13 Clean Trading Card Patch

This patch replaces the browser face-merge/body-swap canvas approach with a clean football trading card generator.

## What changed

- The selfie is rendered as the main portrait inside a premium card frame.
- The selected country controls the entire card theme: colors, flag, badge accents, jersey icon, shorts, socks, and stat bars.
- The selected player is now a mode: Messi Mode, Ronaldo Mode, Mbappe Mode, Neymar Mode.
- No more pasting a face on top of a baked character image.
- No more hidden YUVI 10 jersey text conflicts.
- The generated card is faster and more reliable on mobile.
- Download and Post to Highlights continue to work.

## Supabase

No Supabase changes are required.
